# chinese-site

Public documentation, demonstrations, and learning entry point for Boxi Chinese.

> **Status:** scaffold. The site will publish reviewed scenarios from `chinese-explain` and `chinese-scenarios`.

The site should support text-first lessons, optional aligned audio, characters with pinyin and tone information, accessible transcripts, and an offline-friendly build from pinned content artifacts. It does not own learner records, assessment policy, or private course material.
